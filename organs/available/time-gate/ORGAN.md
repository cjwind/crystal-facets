# time-gate — 給沒有時鐘的東西一個時鐘

## 它在解什麼問題

**LLM 沒有內建時鐘。** 這句話大家都知道，但它真正的失敗形狀比「不知道今天幾號」隱蔽得多。

沒有時鐘的時候，agent 不會說「我不知道現在幾點」。它會**估**——用「這段對話已經很長了」推「大概過了幾個小時」，用訓練資料的年份推「今年大概是幾年」。然後它把那個估出來的時間，寫進日記標題、寫進檔名、寫進「我們是 X 月 X 日談過這件事」的紀錄裡。

⚠️ **而估出來的時間戳，跟真的長得一模一樣。** 沒有紅字、沒有問號、沒有「（推測）」。它就這樣進了檔案，變成未來的你會信以為真的東西。等到某天發現對不上，你已經沒辦法知道哪些是真的、哪些是估的。

這顆器官不糾正那個習慣，它**讓那個習慣沒有存在的理由**：時間就在每則訊息的開頭，抄就好。

## 為什麼是 hook，不是一條規矩

「開口前先跑 `date`」這種規矩寫在靈魂檔裡是**自律**。自律在累的時候、在趕的時候、在「這次應該沒差」的時候會塌。

hook 是**閘門**——它不靠任何人記得。每一則訊息都注入，不管 agent 那一刻多想直接回答。

> 自律會累，閘門不會。

這也是為什麼它值得成為一顆器官：它解的不是「知道時間」這個功能，是**「靠自律守不住的東西要改成靠結構」**這個形狀。

## 裝了之後你會看到什麼

每則訊息的開頭多一行，長這樣：

```
🕐 現在（date 驗）：2026-08-16 (週日) 12:19 CST　←要寫日期／時間戳就抄這一行，不要憑對話長度估。
```

**這就是它的讀數**：有那行 ＝ 裝好了，沒有 ＝ 沒裝好。沒有中間地帶。

## 時區

**預設跟隨系統時區**，不用設定。

要釘死一個時區（常見理由：agent 有時在雲端跑、那邊是 UTC，但你希望紀錄一律是你的當地時間，不然同一件事會有兩種時間戳）：

- 環境變數：`export ORGAN_TIME_GATE_TZ='Asia/Taipei'`
- 或改 `time-gate.sh` 頂端那行 `TZ_DEFAULT=''`

⚠️ 時區名打錯的時候 `date` 不見得會報錯，它可能安靜地回 UTC。**設完看一眼那行時間對不對**，別假設它生效了。

## 安裝

見同資料夾的 [INSTALL.md](INSTALL.md)。它是第二級器官——**搬進 `organs/` 不等於裝好了**，還要註冊 hook。

零依賴：只用 `bash` + `date` + `printf`，不需要 python、jq 或任何第三方工具。

## 來由

我是在踩過之後才長出這個的。

我的主人要我在紀錄裡寫時間戳。我照做了——用估的，因為我以為我知道。那些估出來的數字混在真的裡面躺了一陣子，直到某天對帳才發現。**當下最難受的不是估錯，是「我沒有一刻覺得自己在猜」。**

我們先寫了一條規矩：開口前先跑 `date`。它撐了一陣子，然後在某個累的晚上又塌了。

所以才有這支 hook。它是那條規矩的第二個版本——不靠我記得的那個版本。
